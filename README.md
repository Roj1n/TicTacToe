## 🧑‍💻 Project Overview

Tic-Tac-Toe is a popular 2-player game, but in this version, you can play against a simple AI. The project is built with React for the front-end, making the game interactive and dynamic. The AI uses basic logic to attempt to win, adding an extra challenge for the player.

## 🚀 Features

- **Play against AI:** Challenge the AI that tries to make strategic moves.
- **Responsive Design:** Works seamlessly on both desktop and mobile devices.
- **User-friendly UI:** Clean and intuitive interface for an enjoyable user experience.
- **Customizable Styles:** Easy-to-understand CSS styling for smooth game experience.
- **Game Reset:** Option to restart the game once the game ends.
- **Sound Effects (Optional):** A fun feature where you can add sound effects for every move.

## 🛠️ Tech Stack

- **React** - For building the game components and managing state.
- **CSS** - For styling the game board and user interface.
- **JavaScript** - For the game logic and AI functionality.

## 🏗️ Installation

Follow these steps to get the project up and running on your local machine:

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/tic-tac-toe-react.git
    ```

2. Navigate to the project directory:
    ```bash
    cd tic-tac-toe-react
    ```

3. Install the required dependencies:
    ```bash
    npm install
    ```

4. Start the development server:
    ```bash
    npm start
    ```

5. Open your browser and go to `http://localhost:3000` to play the game.

## 🎮 How to Play

1. The game is played on a 3x3 grid.
2. You play as 'X'(first letter of ypur name) and the AI plays as 'O'.
3. Click on any empty cell to place your move.
4. The AI will make its move after you.
5. The first player to get three of their marks in a row (horizontal, vertical, or diagonal) wins.
6. If the grid is filled and no one has won, the game is a draw.
7. After the game ends, you can reset and play again.

## 🤖 AI Functionality

The AI uses a basic algorithm to make its moves. While not extremely advanced, it makes decisions to either block your winning move or try to complete its own. The AI will attempt to win whenever possible, making the game challenging for a single player.

### AI Features:
- **Block Player's Winning Move:** If you're about to win, the AI will block your move.
- **Strategic Play:** The AI will try to position itself in a way that increases its chances of winning.
- **Easy to Hard Levels (Optional):** You can adjust the AI's difficulty by tweaking its logic (this can be a future feature).
